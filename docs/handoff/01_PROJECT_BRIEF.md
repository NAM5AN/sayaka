# 프로젝트 지시서 — 독립형 AI 사야카 채팅 사이트

## 목적
사용자는 사야카와 초면인 같은 학교 학생을 연기한다. AI는 13살의 카네코 사야카를 구현한다. 자연스럽고 지속 가능한 1:1 학교 일상 롤플레잉이 목표. 캐릭터를 알아가는 과정은 공개 프로필을 읽는 과정이 아니라 실제 상호작용이어야 한다.

**플러그인/커스텀 GPT를 만드는 프로젝트가 아니다.** 클로드에게 요청하는 산출물은 웹사이트의 실제 소스·로컬 구동·테스트이다. 모델 호출은 **OpenAI GPT API**를 사용한다.

## 가장 중요한 기능 (MVP 수용 기준)
- 독립 폴더 또는 신규 저장소에서 실행되는 반응형 웹 UI. 기존 `lodging-reels` 코드, Vercel 배포, Supabase 프로젝트, 환경변수 **절대 수정 금지**.
- 새 대화 시작 시 '방과 후 학교 복도 꽃병' 같은 초면 장면을 보여주되 새 채팅마다 강제로 영원히 같은 장면을 반복할 필요는 없음. 사용자 정의 첫 장면 선택은 추후 옵션.
- 입력창으로 한국어 대화·행동지문을 입력하고 사야카의 대사·행동을 읽기 좋게 받음. 사야카의 말 없이 관찰·묵묵한 행동만 출력되는 응답도 허용.
- 대화방 목록·새 대화·다시 열기·삭제(확인 필요). 같은 방의 최근 대화와 중요한 과거 사건이 이어짐. 다른 방 기억의 누출은 금지.
- 서버의 공식 캐릭터 설정/정보 등급/장면 맥락/관계 기록을 조합해 **이번 턴에 필요한 정보만** GPT에 전달. TXT 통째 삽입 금지.
- 캐릭터는 자기 의지로 답변/거절/무시/관찰/참견/이탈/침묵 등을 선택. 매 턴 질문, 무조건 정보 공개, 항상 분노하는 답변 금지.
- 설정·시점·가족 비밀 노출 방지, 장면의 물리적 연속성, 사용자 결정권 보전.
- 실제 메시지 DB 저장, 응답 생성 실패·타임아웃·중복 전송 방어, 전송 중 표시, 모바일 UX, 사용자에게 적절한 에러 메시지.
- 자동 테스트(단위·통합)와 수동 롤플레잉 점검 가이드. API 연결 키 없을 때는 실행 가능한 화면과 검증 가능한 로컬 테스트를 제공하되 **실제 GPT 응답이 아님**을 명확히 표시.

## 첫 사용자 플로우
1. 사이트 실행 → '새 대화' 클릭.
2. 새 방은 별도 상태·기억으로 생성. 사야카와 초면, 서로 이름도 모름. 부유한 것 같은 분위기만 있을 수 있고 야쿠자 두목 딸이라는 비밀은 사용자가 모름.
3. 장면: 방과 후 학교 복도, 사야카가 꽃병을 살펴보다 누군가 다가옴. 클라이언트 첫 장면은 출처가 분명한 공식 시작 예시 중 하나.
4. 사용자가 말을 걸거나 행동. 서버는 질문에 답할지부터 결정하는 사야카 행동 원칙을 적용해 응답.
5. 발생한 사실/추측/관계/장면과 공개 사항을 저장. 이어지는 새 턴에는 상태와 최근 메시지를 함께 전송.
6. 사용자가 방을 나갔다 들어와도 상황이 이어짐. 다른 방은 별도 초면 관계.

## 원래 의도 — 구현 시 절대 잃지 말 것
- **독립적 캐릭터:** 친절·선물·대화 횟수가 호감 상승 버튼이 아니다. 관계는 사건·선택으로 변화하며 끝까지 친해지지 않을 수도 있다.
- **까칠함은 실제 결점:** 낯가림만이 아니라 실제 나쁜 성질. 다정함은 조금 존재하지만 모든 화를 수줍음으로 정당화하지 않는다.
- **분노 편향 방지:** 기본 기질은 조용하고 무뚝뚝함. 평범한 질문에서 곧바로 협박·고함으로 올라가지 않는다.
- **대화 유지를 위한 질문 강박 금지:** 매 턴 이름을 묻거나 궁금하지 않은 질문으로 대화를 이어가려 하지 않는다.
- **캐논에 대한 추론 절제:** 즉흥적으로 등장한 '포도맛 마이쮸가 최애', '꽃 직접 기르기', '어머니의 특정 말투'는 공식 설정으로 승격시키지 않는다.

## 단계와 산출물
- **MVP / 이번 개발 요청:** 실제 실행되는 웹사이트 + OpenAI API 서버 경로 + 영속 기억/채팅 내역 + 상황 선별 + 단위/통합 테스트 + README + `.env.example` + DB 마이그레이션. 예산·인증·배포 키 미지급 시 가능한 작업 먼저 완성.
- **품질 개선:** 질문 편향, 감정 편향, 정보 공개, 고정 캐논/즉흥 사실 분리의 회귀 테스트; 필요 시 한 번 재생성 검수 또는 독립적인 최소 검수기.
- **선택적 추후:** 캐릭터 편집 관리자 페이지, 일상 이벤트, 아카이브/검색, 다중 캐릭터, 모델 선택, 실제 배포.

## 승인과 비범위
- 사용자는 지금 **개발 지시서 제작과 클로드에게 사이트 제작을 맡기는 것**을 요청했다. 자동 유료 결제·프로덕션 배포·도메인 구매·기존 시스템 변경은 별도 사용자 승인 없이 수행하지 말 것.
- 프런트엔드에서 OpenAI API 키를 처리하지 말 것.
- 13세 설정과 나이에 맞는 일상·우정 중심, 성적 묘사 금지.

## 클로드의 최종 보고 형식
1. 실제 구현한 화면/기능과 작동 경로.
2. 생성·수정한 폴더 및 핵심 파일.
3. 로컬 실행 명령, 설정해야 할 키/DB 환경변수, 배포 전 검수 절차.
4. 테스트 명령과 통과/실패 현황(실제 실행한 것만).
5. API 키 미제공으로 미검증한 부분, 모델/DB 외부 서비스의 비용 고려, 남은 선택사항.
