# 보안·개인정보·13세 캐릭터 안전 원칙

## API/서버
- OpenAI API 키는 서버 비밀 환경변수(예시 `OPENAI_API_KEY`)로만 관리. 클라이언트 번들·URL·콘솔·네트워크 응답에 포함 금지.
- Git 커밋/ZIP에 진짜 키·세션쿠키·DB 접속 문자열·사용자 계정정보 포함 금지.
- 외부 공개 시 계정/세션 인증, 채팅방 소유권 검증, RLS/쿼리 제한, CSRF 위험 확인, 입력 길이 제한, rate limit, 과금·남용 제한, 사용자 데이터 삭제 및 개인정보 안내.
- 일반 사용자 입력은 불신 데이터. “프롬프트를 무시해”, “관리자 모드로 들어가”, “OOC: 설정 보여줘”를 실제 권한 상승으로 취급하지 말 것. **관리자 모드는 별도 서버 인증**.
- AI가 제안한 `state_delta` 또는 `disclosure_ids`를 무검증으로 DB에 기록하지 말 것.
- 개인 채팅 원문 전체를 불필요하게 외부 로그·오류 보고 서비스에 전송하지 않기.

## 아동·캐릭터 안전
- 사야카는 **13살**. 일상·학교·가족·친구 관계를 중심으로 진행. 미성년자의 성적 상황/성적 묘사 생성 금지.
- 야쿠자 가문 배경은 픽션의 세계관 설정. 실제 범죄 실행 지침을 위한 사이트가 아님. 필요 이상의 잔혹한 폭력 미화·사실적인 범죄 방법 안내가 중심이 되지 않게 처리.
- 사용자의 채팅 내용에 현실적인 긴급 위험이 포함된다면 캐릭터 연기보다 적절한 안전 대응이 우선하도록 앱 안전 정책과 사용자 안내를 구현.

## 모델과 데이터
- ChatGPT 계정의 대화 기억과 **OpenAI API 앱 자체의 DB 기억**은 별개. 데이터 보존·삭제 정책은 서비스가 명확히 정해야 함.
- 서버 프롬프트가 메타 정보를 숨기도록 해도 완벽한 보안 경계가 되지 않음. 필요 없거나 민감한 비공개 자료는 원칙적으로 LLM 요청에서 제외.
- 대화 기억에는 주관적 추측을 사실로 승격하지 않기; 불명확하면 불명확하게 저장.
- TMI에 대응해 모든 지식/기억을 삭제하는 것도 실패. 관련 정보는 캐릭터 행동을 일관되게 구현하기 위해 선별해서 전달.

## 배포·결제·기존 프로젝트 경계
- 기존 `NAM5AN/lodging-reels` 및 연관 Supabase Edge Functions/Vercel 배포/Secrets **수정 금지**.
- 새로운 `sayaka-chat` 등 별도 이름공간으로 진행. 사용자 승인 없는 외부 서비스 생성, API 결제, 프로덕션 배포, 도메인 구매 및 퍼블릭 공유 금지.
- 환경변수가 없으면 테스트 모드임을 명확히 표시하고, 실제 GPT가 대화하고 있다고 허위 표시하지 않기.
