## 결정된 사항
- 최종 목표: 커스텀 GPT/플러그인이 아닌 **독립 웹사이트**에서 OpenAI GPT API로 대화.
- 챗봇의 목적: 살아 있는 성격과 선택을 가진 사야카의 몰입형 역할극.
- 기본 사용자 역할: 사야카와 초면인 같은 학교 학생; 같은 반인지는 사용자와 대화에서 정해질 수 있으며 시작부터 고정하지 않음.
- 공식 설정/제작자 비밀/모델에 보낼 정보/사용자가 아는 정보 구분.
- 대답 강요·질문 강박·상시 분노·소지품/장면 모순 방지.
- 대화방별 기억과 관계 추적은 실제 사이트 DB에 구현.
- 초반/기본 사용자는 같은 학교 13세 캐릭터와 나이에 맞는 대화.

## 열린 선택
- 최종 GPT 모델·추론 노력·응답 형식의 튜닝값.
- 실제 호스팅/DB/로그인, 퍼블릭 공개 여부, UI 확정 시안.
- 인물 일러스트/배경 저작권을 충족하는 정식 에셋.
- 캐릭터 가족/선물/마스코트/상징꽃 등 미정 캐논.
- 대화 기록/메모리 데이터 정책: 다른 방 공유 여부(현재 기본은 각 방 분리), 보존기간과 수정/삭제 옵션.
- 자동 검수에 쓸 추가 모델 호출이 필요한지 여부(비용·지연 시험 후 결정).

## ZIP에 포함하지 않은 것
- 기존 플러그인 자체의 설치용 ZIP: **웹사이트 구현 원본이 아니므로 혼동 방지를 위해 제외**. 필요한 캐릭터 프롬프트는 정확히 포함.
- 사용자의 OpenAI API 키 및 인프라 로그인 정보: 보안상 제공되지 않았으며 **사용자에게서 승인·설정된 뒤** 처리해야 함.
- 완성된 웹사이트 소스: 이번 ZIP은 Claude에게 **실제 구현을 시킬 지시·자료 패키지**이며, 웹사이트 자체는 이 단계에서는 미구현.
